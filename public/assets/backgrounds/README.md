# Fonds de saison

Dépose ici quatre illustrations aquarelle de paysage, une par saison :

```
winter.jpg
spring.jpg
summer.jpg
autumn.jpg
```

- Format JPG, cadrage paysage plein écran (par ex. 1920×1080 ou plus), légèrement désaturé pour rester cohérent avec l'arbre.
- Le site choisit automatiquement la bonne image selon la date du jour (hiver : déc-jan-fév, printemps : mar-avr-mai, été : juin-juil-août, automne : sept-oct-nov) et fait un fondu doux entre deux saisons.

**Tant qu'une image n'est pas présente**, un dégradé aquarelle de secours est utilisé pour cette saison (voir les classes `.fallback-*` dans `css/style.css`), pour que l'expérience reste complète en attendant les illustrations définitives.
